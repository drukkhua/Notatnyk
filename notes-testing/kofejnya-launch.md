## Формат точки
| Параметр | Значение |
| **площадь** | 45 м² |
| **формат** | to-go + 8 посадочных |
| **проходимость** | ~140 чашек/день |
| **режим** | 26 рабочих дней/мес |
| **чек (средний)** | *65 грн за напиток* |
