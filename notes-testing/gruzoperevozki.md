# Квартирный переезд — смета
17.07.2026г. 14:15
> @Наталья
> Переезд из двушки в новую квартиру, другой район. Есть пианино и большой шкаф-купе. Нужны грузчики, разборка-сборка и машина. Посчитайте по километрам и часам.

## Параметры переезда
| Параметр | Значение |
| **откуда → куда** | Салтовка → Алексеевка |
| **расстояние** | 18 км |
| **этаж (откуда / куда)** | 5 без лифта / 9 с лифтом |
| **грузчиков** | 4 |
| **часов работы** | 6 |

===
### Блок переменных
[km] = 18
[loaders] = 4
[hours] = 6
[rate_h] = 320
[floor] = 5

/* внутреннее
грузчикам платим [rate_h]*0.55 за час, остальное — маржа
топливо Газель ≈ [km]*2*14 =
пианино — риск, страхуем, наценка отдельно
*/

===
1. Работа грузчиков
### Погрузка, подъём, разгрузка
---
- работа грузчиков = [loaders] * [hours] * [rate_h] = грн
- подъём без лифта (5 этаж) = [floor] * [loaders] * 40 = грн
- разборка/сборка мебели = 2400 грн
- такелаж пианино = 3500 грн
// себестоимость бригады ≈ [loaders]*[hours]*180 =
- упаковка и стретч-плёнка = 900 грн
---
Итого: 15280 грн [4 грузчика]

===
2. Транспорт
### Машина и пробег
---
- подача Газели = 800 грн
- пробег по маршруту = [km] * 2 * 22 = грн
- ожидание и простой = [hours] * 120 = грн
- платный въезд/парковка = 300 грн
---
Итого: 2612 грн [18 км]

===
! Стоимость часа бригады — в переменной [rate_h]; при ночном тарифе меняем одно число
!! Хрупкое (пианино, зеркала) страхуем отдельно — без страховки такелаж не берём
