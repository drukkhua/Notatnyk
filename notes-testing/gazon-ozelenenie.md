# Газон и озеленение участка — смета
17.07.2026г. 15:53
> @Дмитрий
> Участок 6 соток, хотим рулонный газон на 320 м², автополив, живую изгородь по периметру и несколько хвойных. Нужен расчёт с посадкой и запуском полива.

### Участок
| Параметр | Значение |
| **площадь газона** | 320 м² |
| **периметр изгороди** | 90 м.п. |
| **хвойных (крупномер)** | 8 |
| **зон полива** | 5 |
| **уклон** | небольшой, планировка нужна |

===
### Блок переменных
[lawn] = 320
[hedge] = 90
[trees] = 8
[zones] = 5
/* себестоимость — внутреннее
рулон газона закуп = [lawn]*95 =
саженцы туи опт = [hedge]*145 =
трубы + форсунки Hunter = [zones]*1800 =
бригада озеленителей 3 чел × 4 смены
маржа по материалам 25%, по работе — наша

===
1. Газон и планировка
### Подготовка и укладка
---
- планировка и культивация = [lawn] * 45 = грн
- плодородный грунт (завоз + разравнивание) = [lawn] * 80 = грн
- укладка рулонного газона = [lawn] * 120 = грн
- рулонный газон (материал) = [lawn] * 110 = грн
// себестоимость газона ≈ [lawn]*95 + [lawn]*55 =
- первый прикатка + запуск = 2500 грн
---
Итого: 116100 грн [320 м²]

===
2. Озеленение и автополив
### Изгородь, деревья, система
---
- посадка живой изгороди = [hedge] * 260 = грн
- саженцы туи по периметру = [hedge] * 190 = грн
- посадка хвойных крупномеров = [trees] * 850 = грн
- монтаж автополива = [zones] * 3200 = грн
---
Итого: 63300 грн [320 м²]

===
! Цена за м² газона = Итого газона ÷ [lawn] м² — сразу видно
!! Рулонный газон укладываем в течение 24 ч после срезки — согласуйте день завоза заранее
