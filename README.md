# Notatnyk

**Notatnyk — сопутствующий блокнот для [BrightPrint CRM](https://www.brightprint.com.ua/): в нём удобно собирать требования клиента, считать варианты и оформлять черновик технического задания до создания заказа.**

Вы пишете обычным текстом, а Notatnyk сразу показывает оформленный документ: заголовки, списки, таблицы, чекбоксы, расчёты и эскизы размеров. Когда параметры согласованы, кнопка «Скопировать документ» переносит исходный текст с разметкой в буфер обмена. Его можно вставить в поле «Техническое задание» заказа BrightPrint CRM и продолжить работу уже в контексте клиента, макета, производства и оплаты.

## Зачем это

До подтверждения заказа клиент часто меняет тираж, материал, отделку и срок. В этот момент нужно быстро записывать детали, сравнивать варианты и пересчитывать стоимость. Notatnyk даёт для этого отдельное рабочее место: заметка остаётся свободным текстом, но уже выглядит как понятное ТЗ.

### Как Notatnyk работает вместе с BrightPrint CRM

1. **Соберите запрос**: параметры изделия, цитаты клиента, варианты исполнения и вопросы, которые ещё нужно уточнить.
2. **Посчитайте стоимость** прямо в заметке: формулы, суммы по позициям и итог обновляются при правках.
3. **Проверьте оформление**: разметка превращается в читаемые секции, таблицы, чекбоксы и эскизы размеров.
4. **Перенесите согласованное ТЗ**: нажмите «Скопировать документ» и вставьте текст в поле ТЗ заказа BrightPrint CRM.

Перенос выполняется копированием и вставкой: автоматической синхронизации заметок с CRM сейчас нет. Копируется исходный текст, а не HTML-предпросмотр. Базовая разметка ТЗ отображается в CRM; после вставки проверьте итог и оформление, особенно если использовали специфические возможности Notatnyk.

## Возможности

### Деньги и расчёты
- **Автосумма Σ** — цены с `=` (или `:` — равноправно) складываются автоматически; поддерживаются дробные суммы (`= 14 322,56 грн`).
- **Секции и «Итого»** — несколько смет в одном документе; каждое `Итого` сверяется с суммой позиций выше (`✓` / `✕` + разница), внизу — разбивка по всем итогам.
- **Калькулятор в тексте** — `55*3+7*(2.5+3.5)*2.55=` → `272,1`. Поддержка `+ − * / % ^` и скобок, округление до 2 знаков. Результат можно сразу сделать ценой в Σ (`… = грн`).
- **Переменные** — `[листов] = 1125` (можно формулой); ссылайся в расчётах `18400/1200*[листов]=`. Поменял в одном месте — пересчиталась вся смета.
- **Цена за единицу** — `[4000 шт]` делит ближайшее `Итого` на количество → `(13,75 грн/шт)`. Единичные `грн/шт` показываются, но в Σ не идут.
- **Скрытие себестоимости** — `// строка` и блок `/*` … `*/` не видны в рендере, но **продолжают считаться**; наоборот, `\=` / `\:` отключают правило Σ на конкретной строке.

### Оформление и передача ТЗ
- **Мгновенная вёрстка** — заголовки, списки, таблицы, предупреждения, чекбоксы и эскизы размеров оформляются по мере набора текста.
- **Копирование для CRM** — отдельная команда копирует исходник заметки вместе с разметкой, формулами и скрытыми строками для вставки в поле ТЗ.
- **Отдельный HTML-экспорт** — можно сохранить самодостаточный документ для просмотра вне приложения. Это дополнительный способ поделиться расчётом, а не способ переноса ТЗ в BrightPrint CRM.

### Редактор
- **Симбиоз-режим (β)** — правишь исходник с подсветкой синтаксиса и одновременно видишь готовый вид; спец-символы не ломают виджеты. На телефоне — основной режим (без разделения экрана; переключается в 100% рендер / 100% исходник).
- **Как в IDE** — номера строк, тонированный фон источника, скролл панелей синхронизирован **по строкам** (не «по процентам» — таблицы и скрытые блоки не сбивают соответствие).
- **Шрифт документа** — меню «Aa»: 7 кросс-ОС пресетов с полной кириллицей и ровными цифрами, размер S/M/L; режим «Документ» для печатного вида.

### Текст и организация
- **Разметка** — заголовки, списки и нумерация, callout (`!` / `!!`), таблицы `| A | B |`, разделители, `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `==выделение==`, инлайн-код `` `код` `` (моноширинный в рамке, содержимое дословно — удобно для технических названий и команд), авто-типографика (`->` → →, `=>` → ⇒, `м2` → м², `(c)` → ©, `+-` → ± и др.), ссылки, дата `[date]` / `[date:time]` (фиксируется при вводе).
- **Эскизы изделий** — `[50x90мм]` рисует пропорциональный прямоугольник с X-крестом и размерными стрелками; `[d50мм]` — круг с ø и центровым крестом. Оба плывут влево: текст обтекает газетными колонками. Модификаторы: `r5` — скруглённые углы 5 мм; `+3` — вылет (bleed) 3 мм; `fold` — линия биговки (X делится на две секции). Комбинируются: `[210x99мм+3 r5 fold]`. Эскизы — только визуальные, в Σ не участвуют.
- **Чекбоксы** — `[ ]` / `[x]`, клик прямо в рендере переключает статус.
- **Цитата клиента** — `> текст` + `> @Имя`: карточка с аватаром-инициалом, видно, чей это просчёт.
- **Быстрый поиск** по всем заметкам без учёта регистра и camelCase.
- **Языки** — ru / uk / en; ключевые слова (валюта, «Итого», единица и др.) настраиваются.
- **Своя папка хранения** (например, в облачной синхронизации), светлая/тёмная тема, иконки Lucide (инлайн-SVG, без зависимостей), встроенная шпаргалка (`?`) и панель вставки паттернов.

## Платформы

Один код → нативные приложения под **macOS, Windows, Android и iOS** (Tauri 2).

Сборку делает CI: по `git push` в `main` (и по тегу `v*`) GitHub Actions собирает
установщики под все платформы — macOS универсальный `.dmg`, Windows `.msi`/`.exe`,
Android `.apk`, iOS-сборку. Готовые файлы — в Artifacts прогона; по тегу создаётся
черновик GitHub Release с установщиками для десктопа.

> iOS: устанавливаемый на iPhone `.ipa` требует платного Apple Developer-аккаунта
> (ограничение Apple). Без него CI лишь проверяет, что проект собирается. Подробности
> и настройка подписи — в [`КАК_ЗАПУСТИТЬ.md`](КАК_ЗАПУСТИТЬ.md).

В сборку упакованы 10 демо-смет — при первом запуске они появляются в приложении как примеры.

## Хранение

Каждая заметка — один `.md` файл, и всё (без служебных `.json`). Заголовок берётся из первой строки, а дата и время последней правки — из времени изменения файла (в списке под названием: `16.07.2026 14:23`, свежие сверху). Никакого облака по умолчанию: всё локально, в папке приложения или в выбранной вами папке.

## Быстрый старт

Нужны **Rust** (https://rustup.rs) и **Node.js 20+**.

```bash
npm install
npm run dev      # запуск в режиме разработки
npm run build    # собрать установщик (.dmg/.app или .msi/.exe)
```

Android:

```bash
npm run android:init     # один раз
npm run android:dev
npm run android:build
```

Готовые сборки под все платформы удобнее получать из CI: по `git push` GitHub Actions
собирает установщики (см. раздел «Платформы»). Подробнее — [`КАК_ЗАПУСТИТЬ.md`](КАК_ЗАПУСТИТЬ.md).

## Синтаксис

Краткая шпаргалка (полная — в приложении по кнопке `?` и в [`КАК_ЗАПУСТИТЬ.md`](КАК_ЗАПУСТИТЬ.md)):

| Пишешь | Получаешь |
|---|---|
| `#` / `##` / `###` | заголовки |
| `[ ]` / `[x]` | чекбокс |
| `- ` / `1.` | список / нумерация |
| `! ` / `!! ` | выноска (жёлтая / красная) |
| `> текст` + `> @Имя` | карточка-цитата клиента |
| `= 12 450 грн` **или** `: 12 450 грн` | цена в Σ (дробные ок: `= 14 322,56 грн`) |
| `\= 500 грн` | отключить правило Σ на строке (слэш в рендер не идёт) |
| `грн/шт` | цена за штуку (не в Σ) |
| `55*3+(2.5+3.5)*2=` | калькулятор → результат |
| `[листов] = 1125` | переменная (число или формула) |
| `Итого: N грн` | подытог секции со сверкой |
| `Итого общее: N грн` / `Итого общ.: N грн` / `Разом загалом: N грн` / `Разом заг.: N грн` | общий итог со сверкой суммы подытогов |
| `[4000 шт]` | цена за единицу от ближайшего `Итого` |
| `\| A \| B \|` | таблица |
| `` `код` `` | инлайн-код: моноширинный шрифт в рамке (содержимое дословно) |
| `->` `<-` `<->` | стрелки → ← ↔ |
| `=>` `<=` `<=>` | двойные стрелки ⇒ ⇐ ⇔ |
| `[50x90мм]` | эскиз: прямоугольник с X-крестом и размерными стрелками |
| `[50x90мм r5]` | + скруглённые углы 5 мм |
| `[50x90мм+3]` | + вылет (bleed) 3 мм |
| `[210x99мм fold]` | + биговка: линия сгиба, X в каждой секции отдельно |
| `[d50мм]` / `[d50мм+3]` | эскиз: круг ø50 мм; `+3` — с вылетом |
| `[date]` / `[date:time]` | текущая дата |
| `// строка` | скрытая строка — не видна, но считается в Σ |
| `/*` … `*/` | скрытый блок строк — не виден, но считается в Σ |

## Технологии

- **Tauri 2** — нативная оболочка и системный webview.
- **Rust** — бэкенд (файловое хранилище, диалог выбора папки).
- **Ванильный JS/CSS** без бандлеров и фреймворков — движок разметки в одном файле (`src/parser.js`), UI в `src/main.js`. Ставка на лёгкость, простоту и надёжность.
