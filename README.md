# Notatnyk

**Лёгкий блокнот для заметок и расчёта стоимости продукции прямо в тексте — без постоянного пересчёта в калькуляторе.**

Notatnyk — это быстрый локальный блокнот с собственным «движком» разметки. Пишешь смету обычным текстом, а приложение само считает суммы, проверяет итоги по секциям, вычисляет выражения и цену за единицу. Запускается мгновенно, как калькулятор: это не браузер и не Electron, а нативный бинарник на системном webview (мегабайты, не сотни).

## Зачем это

Когда считаешь стоимость заказа (печать, материалы, работы), обычно приходится держать рядом калькулятор и вручную пересчитывать всё при каждой правке. Notatnyk убирает этот шаг: цены, формулы и итоги живут прямо в заметке и пересчитываются на лету. Идеально для смет, прайсов, чек-листов производства.

Приложение будет дорабатываться, но основной концепт — «текстовая заметка, которая сама считает» — останется в этом виде.

## Возможности

- **Автосумма Σ** — все цены с `=` складываются автоматически.
- **Секции и «Итого»** — несколько блоков-смет в одном документе; каждое `Итого` сверяется с суммой позиций выше (`✓` / `✕` + разница), внизу — разбивка по всем итогам.
- **Калькулятор в тексте** — `55*3+7*(2.5+3.5)*2.55=` → `272,1`. Поддержка `+ − * / % ^` и скобок, округление до 2 знаков. Результат можно сразу сделать ценой в Σ (`… = грн`).
- **Цена за единицу** — шаблон `[4000 шт]` делит ближайшее `Итого` на количество → `(13,75 грн/шт)`.
- **Единичные цены `грн/шт`** — показываются, но не попадают в общую сумму.
- **Скрытие** — `// строка` и блок `/*` … `*/` не попадают в рендер, но **продолжают считаться**: внутреннюю себестоимость можно держать вне глаз клиента, не теряя её в Σ.
- **Таблицы** — простой синтаксис `| A | B |`, кнопка спрашивает число столбцов и строк.
- **Чекбоксы** — `[ ]` / `[x]`, клик прямо в рендере переключает статус.
- **Цитата клиента** — строки с `> `; `> @Имя` подписывает карточку (аватар-инициал + имя): видно, чей это просчёт.
- **Дата** — `[date]` → `16.07.2026р`, `[date:time]` → `16.07.2026р. 14:23` (впечатывается в текст и фиксируется, не пересчитывается при открытии).
- **Разметка** — заголовки, списки, callout, разделители, `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, `==выделение==`, ссылки.
- **Быстрый поиск** по всем заметкам без учёта регистра и camelCase.
- **Своя папка хранения** — можно держать заметки в любой папке (например, в облачной синхронизации).
- **Языки** — интерфейс на русском по умолчанию, переключается на украинский и английский; ключевые слова (валюта, «Итого», единица и др.) настраиваются.
- **Редактор как в IDE** — номера строк, фон источника чуть отличается от рендера, скролл двух панелей синхронизирован по строкам (не «по процентам» — таблицы и скрытые блоки не сбивают соответствие).
- **Мелочи для удобства** — светлая/тёмная тема, иконки Lucide (инлайн-SVG, без зависимостей), перетаскиваемый разделитель панелей, встроенная шпаргалка по синтаксису (`?`), панель кнопок для вставки любого паттерна.

## Платформы

Один код → нативные приложения под **macOS, Windows и Android** (Tauri 2). Сборка каждой платформы выполняется на этой платформе (или через GitHub Actions).

## Хранение

Каждая заметка — один `.md` файл, и всё (без служебных `.json`). Заголовок берётся из первой строки, а дата и время последней правки — из времени изменения файла (в списке под названием: `16.07.2026 14:23`, свежие сверху). Никакого облака по умолчанию: всё локально, в папке приложения или в выбранной вами папке.

## Быстрый старт

Нужны **Rust** (https://rustup.rs) и **Node.js 20+**.

```bash
npm install
npm run dev      # запуск в режиме разработки
npm run build    # собрать установщик (.dmg/.app или .msi/.exe)
```

Android:

```bash
npm run android:init     # один раз
npm run android:dev
npm run android:build
```

Подробнее (сборка под три платформы, GitHub Actions) — см. [`КАК_ЗАПУСТИТЬ.md`](КАК_ЗАПУСТИТЬ.md).

## Синтаксис

Краткая шпаргалка (полная — в приложении по кнопке `?` и в [`КАК_ЗАПУСТИТЬ.md`](КАК_ЗАПУСТИТЬ.md)):

| Пишешь | Получаешь |
|---|---|
| `#` / `##` / `###` | заголовки |
| `[ ]` / `[x]` | чекбокс |
| `- ` / `1.` | список / нумерация |
| `! ` / `!! ` | выноска (жёлтая / красная) |
| `> текст` + `> @Имя` | карточка-цитата клиента |
| `= 12 450 грн` | цена в Σ |
| `грн/шт` | цена за штуку (не в Σ) |
| `55*3+(2.5+3.5)*2=` | калькулятор → результат |
| `Итого: N грн` | подытог секции со сверкой |
| `[4000 шт]` | цена за единицу от ближайшего `Итого` |
| `\| A \| B \|` | таблица |
| `[date]` / `[date:time]` | текущая дата |
| `// строка` | скрытая строка — не видна, но считается в Σ |
| `/*` … `*/` | скрытый блок строк — не виден, но считается в Σ |

## Технологии

- **Tauri 2** — нативная оболочка и системный webview.
- **Rust** — бэкенд (файловое хранилище, диалог выбора папки).
- **Ванильный JS/CSS** без бандлеров и фреймворков — движок разметки в одном файле (`src/parser.js`), UI в `src/main.js`. Ставка на лёгкость, простоту и надёжность.
