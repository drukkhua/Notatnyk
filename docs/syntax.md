# Синтаксис Notatnyk — полный справочник (аудит паттернов)

> Единый источник правды по разметке. Каждый паттерн ниже реализован в движке
> (`src/parser.js`) и должен присутствовать в шпаргалке приложения (кнопка **«?»**,
> строится из `buildSyntax()` в `src/main.js` → `I18N.*` подсказки). Колонка **«?»** —
> есть ли строка в шпаргалке; **«Тулбар»** — есть ли кнопка вставки.
> Ключевые слова (валюта `грн`, `Итого`, `шт`, спец-имена `оплата`/`депозит`/…)
> локализуемы (ru/uk/en + ручные правки в «Настройках»), примеры даны для ru.
> Аудит 19.07.2026: добавлены строковые переменные, спец-переменные денежной петли
> и `:`-цена — все внесены в шпаргалку.

## 1. Структура (группа «Структура»)

| Паттерн | Что делает | «?» | Тулбар |
|---|---|---|---|
| `# ` / `## ` / `### ` | заголовки H1/H2/H3 (H1 — синий); шапка сворачиваемой секции | ✓ | ✓ (меню H1/H2/H3) |
| `- ` / `* ` | список с маркером | ✓ | ✓ |
| `1. ` | нумерованная позиция | ✓ | ✓ |
| `[ ] ` / `[x] ` | чек-бокс (клик отмечает «ГОТОВО»); правит исходник | ✓ | ✓ |
| `> …` | цитата; `> @Имя` — карточка клиента (в Σ не идёт) | ✓ | ✓ |
| `\| A \| B \|` | таблица (1-я строка — заголовки); `\|---\|` — разделитель | ✓ | ✓ (диалог) |
| `! ` / `!! ` | выноска: `!` жёлтая (внимание), `!!` красная (опасно) | ✓ | ✓ (меню) |
| `---` | тонкий разделитель | ✓ | ✓ (меню) |
| `===` | жирный разделитель | ✓ | ✓ (в меню `---`) |
| `// …` | скрытая строка — не видна, но считается в Σ | ✓ | ✓ |
| `/* … */` | скрытый блок → чип `🙈 внутренние расчёты (N)`; в Σ идёт, в экспорт — нет | ✓ | ✓ |

## 2. Инлайн-стили (группа «Инлайн-стили»)

| Паттерн | Что делает | «?» | Тулбар |
|---|---|---|---|
| `**жирный**` | жирный | ✓ | ✓ (Cmd/Ctrl+B) |
| `*курсив*` | курсив | ✓ | ✓ (Cmd/Ctrl+I) |
| `~~зачёркнуто~~` | зачёркнутый | ✓ | ✓ |
| `==выделить==` | выделение маркером | ✓ | ✓ |
| `https://…` | кликабельная ссылка (авто) | ✓ | — |
| `[date]` | текущая дата, впечатывается в текст | ✓ | ✓ |
| `[date:time]` | дата со временем | ✓ | ✓ |

## 3. Деньги и расчёты (группа «Деньги и расчёты»)

| Паттерн | Что делает | «?» | Тулбар |
|---|---|---|---|
| `[имя] = формула` | переменная (число/выражение); правишь в одном месте — пересчёт везде | ✓ | ✓ |
| `[имя]` | ссылка на переменную в формуле/тексте | ✓ | — |
| `55*3+(2.5+3.5)*2=` | калькулятор → результат (`+ − * / % ^` и скобки) | ✓ | ✓ |
| `18400/1200*1125= грн` | результат калькулятора как цена в Σ | ✓ | — |
| `= 12 450 грн` **или** `: 12 450 грн` | цена в Σ (синий чип); `=` и `:` равноправны | ✓ | ✓ |
| `2490 грн` / `- 2490 грн` | цена вне Σ (без `=`/`:`) | ✓ | — |
| `грн/шт` | цена за штуку — показывается, НЕ суммируется | ✓ | ✓ |
| `Итого: N грн` | подытог секции — сверяется с суммой позиций выше (✓/✕) | ✓ | ✓ |
| `[4000 шт]` | цена за единицу: ближайшее «Итого» ÷ кол-во (дробное ок: `[4,2 м.п.]`) | ✓ | ✓ |

**Про `%` и `^`:** в калькуляторе `a±b%` = процент от суммы, `a*b%` = процент, `b%` = b/100,
`^` — степень (право-ассоциативно). Только внутри калькулятора (перед `=`).

## 4. Смета клиенту — денежная петля (группа «Смета клиенту»)

Строковые и спец-переменные. В «Документе»/экспорте («Отдать клиенту») превращаются в
кнопки и штампы. Только в шпаргалке (без кнопок тулбара — бюджет хрома).

| Паттерн | Что делает | «?» | Тулбар |
|---|---|---|---|
| `[имя] = текст` | строковая переменная (не число): подставляется как текст | ✓ | — |
| `[оплата] = https://…` | ссылка оплаты → кнопка «Оплатить» в документе (Stripe/PayPal/…) | ✓ | — |
| `[депозит] = 30%` | депозит: % от «Итого» или сумма → «Принять и внести депозит» | ✓ | — |
| `[действительна до] = 01.08` | срок действия сметы → штамп в документе | ✓ | — |
| `[email] = …` | адрес для кнопки «Принять» (mailto) | ✓ | — |

*EN-алиасы работают всегда, независимо от языка UI:* `[pay]`, `[deposit]`, `[valid until]`, `[email]`.
Спец-имена локализуемы (ru: `оплата`/`депозит`/`действительна до`; uk: `дійсна до`; en: `pay`/`deposit`/`valid until`).

## 5. Компактный вид (UI-жест, не текстовый паттерн)

- **Тап по заголовку** секции — свернуть/развернуть; свёрнутая шапка показывает свод
  `1/4 ✓ · Итого: N грн`. Состояние — в localStorage per-note, не в `.md`.
- **«Свернуть/Развернуть всё»** — кнопка в футере (появляется при наличии секций).
- На телефоне длинные секции свёрнуты по умолчанию.

## 6. Σ и сверка (пояснение в шапке шпаргалки)

Внизу окна — **Σ позиций**: автосумма всех цен с `=`/`:` (включая калькулятор `…= грн`).
Строка `Итого: N грн` сверяется с ней: **✓** совпадает, **✕** и разница — если нет.
Приложение не знает «правильной» суммы — показывает, сходится ли автосумма с тем, что
вписано в `Итого`. Строки `Итого` в счёт позиций НЕ входят (это сверка секции).
