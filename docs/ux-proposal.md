# UI/UX: киллер-фича мобайла + чего не хватает десктопу

> Проработка 19.07.2026 по референсу заказчика — рабочая реализация в другом его проекте:
> `/Volumes/Main/BitrixUI/frontend/src/` (`lib/specEngine.ts`, `components/SpecEditor.tsx`,
> `components/SpecChecklist.tsx`, `styles/spec.css`). Это TS-порт нашего `parser.js`,
> **уже расширенный** блочным рендером, сворачиванием секций и симбиоз-редактором. То есть
> самый рискованный кусок плана (Э3, contenteditable) у нас **уже есть в работающем виде** —
> осталось адаптировать под мобайл-первичность и лёгкость. Дополняет [[development-plan]]
> Э3/Этап-М и [[complexity-audit]]. 50% скачиваний — телефон, где две панели не показать.

## 0. Вердикт: киллер-фича уже спроектирована тобой — назовём её словами

**«Смета как живой денежный конспект, который сворачивается до одних сумм и раскрывается
касанием ровно там, где ты дотронулся».** Никакого разделения экрана, никакого переключения
«режим правки / режим просмотра» — **одна поверхность**, которая:
- в покое показывает смету с **тапабельными чек-боксами** и **сворачиваемыми секциями**
  (свёрнутая секция = `▸ Газон · Итого: 116 100 грн` — читаешь смету как оглавление по деньгам);
- по касанию строки **та же поверхность становится редактором-симбиозом** с курсором в точке
  тапа (разметка серым, форматирование и пересчёт — вживую);
- всё это **офлайн, одним пальцем, на объекте**.

Это и есть «маленькое, но очень удобное», за которое полюбят: конкуренты (AI-волна,
[[competitive-landscape]]) — это web-билдеры на десктопе; Jobber/Joist — тяжёлые формы.
Ни у кого нет «смета-конспект, сворачиваемая до денег, правится касанием, считает мгновенно».

до нужной модели. Порт назад в ваниль-JS дешёв и снимает главный риск плана.

## 2. Мобильная модель: одна поверхность, два состояния (без сплита)

```
┌──────────────────────────┐     тап по строке / ✏      ┌──────────────────────────┐
│  СМЕТА (интерактив)       │  ───────────────────────▶  │  СИМБИОЗ-РЕДАКТОР          │
│  ▾ Газон  Итого 116 100 ₴ │                            │  # Газон                  │  ← разметка серым
│    ☑ замер                │                            │  - планировка = [lawn]*45 │  ← формула+результат
│    ☐ укладка              │  ◀───────────────────────  │    = 14 400 ₴             │
│  ▸ Полив  Итого 63 300 ₴  │        тап «Готово»        │  ☐ укладка                │  ← чек-бокс тапабелен
│  🙈 внутренние (5)         │                            └──────────────────────────┘
│  Σ 179 400 ₴  ✓            │       нижняя панель: [☰][👁/✏][＋][⇪ Отдать]
└──────────────────────────┘
```

**Правила взаимодействия (из референса, адаптированы):**
1. **Покой = интерактивный рендер.** Тап по чек-боксу — отметить; тап по шапке секции —
   свернуть/развернуть; тап по 🙈 — раскрыть скрытое; тап по строке — открыть правку в этой строке.
2. **Правка = та же область** превращается в симбиоз-холст, курсор в точке касания. Кнопка
   «Готово» возвращает в интерактив. Никаких двух панелей.
3. **Свёрнуто по умолчанию на телефоне** (эвристика `longSectionKeys`: секции >10 строк / таблицы
   >4 рядов). Открываешь смету — видишь **оглавление из денег**, разворачиваешь нужное.
4. **Состояние свёрнутости — в `config.json`/localStorage**, не в `.md` (чистые файлы).

### Что ДОБАВИТЬ к референсу (он десктоп-first, мы — мобайл-first):
- **IME-безопасность (P0).** Референс перерисовывает строку по debounce 300 мс — на Android
  GBoard-composition это роняет символы. У нас: **не трогать активную строку во время
  `compositionstart…end`**, патчить только после `compositionend`/ухода курсора. Это наше
  единственное реальное улучшение поверх рабочего кода — но для мобайла критичное.
- **Патч только изменённых строк**, а не `innerHTML` целиком (референс перерисовывает всё —
  на смете ок, на длинной заметке заметно). Кэш «строка+хеш» (наш Э3.2).
- **Клавиатурная панель-аксессуар** над клавиатурой (`visualViewport`): денежные клавиши
  `= $`, `[имя]=`, `?`, Tab-к-след-`?`, `//`, чек-бокс, `[депозит]`. Это и есть мобильный тулбар.
- **Пульс пересчёта.** Изменил цифру → зависимая `Итого` на 200 мс подсвечивается. Видимое
  «оно пересчитало» = дофамин + доверие (у Kickflip живая цена — та же идея, [[competitive-landscape]] §5).
- **Липкая шапка свёрнутой секции** при скролле — всегда видно, в какой ты секции и её Итого.
- **Свайп по заметке в списке** — удалить (с undo); долгий тап по строке — контекст
  (дублировать / в шаблон / скрыть `//`).

## 3. Десктоп: он хорош, но не хватает трёх вещей (о которых ты просил рассказать)

Текущий сплит (источник+гаттер | рендер, перетаскиваемый делитель) — оставляем, он удобен.
Чего не хватает:

1. **Сворачивание секций и в рендере десктопа** (не только мобайл). Длинная смета на
   10 позиций × 3 секции = простыня; клик по `Итого`-заголовку сворачивает — получаешь
   **оглавление-обзор по деньгам** и на большом экране. Это тот же `groupBlocks()` — бесплатно.
2. **Slash-вставка `/`** как клавиатурная альтернатива тулбару. Печатаешь `/` → меню
   `таблица · Итого · переменная · депозит · оплата · клиент`. Современно (Notion-паттерн),
   **разгружает тулбар** (бюджет хрома ≤7, [[complexity-audit]] §5), и, в отличие от кнопок,
   переносится на мобайл. Мощнее всего именно на десктопе (клавиатура-first).
3. **Командная палитра `Cmd/Ctrl+K`** — прыжок к заметке/клиенту + быстрые действия
   (новый из шаблона, «Документ», «Отдать», сменить шрифт). Power-user-стандарт (Linear/Notion),
   почти бесплатно на нашем поиске, который уже есть. Делает десктоп «быстрым, как калькулятор»
   без мыши.

Мелочи-бонусы: горячие клавиши на `Документ`/`Отдать`; Cmd+F поиск **внутри** заметки для длинных смет.

## 5. Порядок внедрения (от низкого риска к высокому)

1. **Блочный рендер + сворачивание секций** (порт `groupBlocks/sectionSummary/longSectionKeys`
   из референса) — **низкий риск**, работает и на десктопе, и на мобайле, даёт компактный вид
   М.2 сразу. Скрытый блок → `<details>` 🙈. *Начать с этого.*
2. **Одиночная поверхность на телефоне**: рендер-интерактив (тап-чек-бокс, тап-сворачивание,
   тап-в-правку) + нижняя панель. Средний риск.
3. **Симбиоз-редактор** (`renderSourceLines` + каретка из референса) **+ наша IME-защита** и
   патч-по-строкам. Высокий риск — но у нас рабочий образец, а не с нуля. Вечный fallback
   «Исходник» (textarea) остаётся (референс тоже держит третий режим «Исходник»).
4. **Клавиатурная панель над клавиатурой**, пульс пересчёта, липкие шапки.
5. **Десктоп-плюсы**: slash-вставка `/`, командная палитра `Cmd+K`.

Каждый шаг — против бюджетов [[complexity-audit]] §5 и тест-матрицы Этап-М.
