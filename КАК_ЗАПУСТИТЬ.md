# Notatnyk — одно приложение на mac + Windows + Android (Tauri 2)

Один код → нативные приложения под все три платформы. Внутри — твой движок
(чекбоксы, цены с `=` в Σ, callout, темы) как фронтенд, Rust-бэкенд, локальное
хранение заметок в файлах. Это НЕ браузер и НЕ Electron: настоящий лёгкий бинарник
(мегабайты, не сотни), использует системный webview.

## Что поставить один раз
- **Rust** (https://rustup.rs) — `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
- **Node.js 20+** (https://nodejs.org)
- Для Android дополнительно: Android Studio + NDK (см. https://v2.tauri.app/start/prerequisites/)

## Запуск на компьютере (mac или Windows — одинаково)
```
cd notatnyk-tauri
npm install
npm run dev        # запустить в режиме разработки
npm run build      # собрать установщик
```
После `build` готовые файлы лежат в `src-tauri/target/release/bundle/`:
- **macOS**: `.dmg` и `.app`  (на Apple Silicon соберётся под ARM автоматически)
- **Windows**: `.msi` и `.exe`  (эту команду нужно запускать НА Windows-машине)

> Важно: кросс-компиляция ограничена. `.dmg` собирается на маке, `.exe` — на Windows.
> Один и тот же код, но финальную сборку каждой платформы делаешь на этой платформе
> (либо через GitHub Actions — см. ниже).

## Android
```
npm run android:init      # один раз
npm run android:dev       # запуск на подключённом телефоне/эмуляторе
npm run android:build     # собрать .apk / .aab
```
APK появится в `src-tauri/gen/android/app/build/outputs/`.

## Где хранятся заметки
По умолчанию — локально, в папке приложения (AppData):
- macOS: `~/Library/Application Support/com.local.notatnyk/notatnyk/`
- Windows: `%APPDATA%\com.local.notatnyk\notatnyk\`
- Android: внутренняя память приложения
Каждая заметка = один `.md` файл, и всё (без служебных `.json`). Заголовок берётся
из первой строки, а дата и время последней правки (`16.07.2026 14:23` под названием
в списке) — из времени изменения файла, поэтому они честны и после перезапуска.
Список отсортирован по ней: свежее — сверху. Никакого облака.

Кнопка **📁 Папка** в боковой панели позволяет выбрать любую свою папку для
хранения (например, в Documents или на диске синхронизации). Выбор запоминается
в `config.json` рядом с настройками; чтобы вернуться к папке по умолчанию —
удали `config.json`.

## Демо-сметы в коробке
В сборку упакованы 10 демо-смет (`notes-testing/*.md`). При **первом** запуске,
если папки заметок ещё нет, приложение копирует их в неё — продукт открывается не
пустым, а с примерами. Твои данные не трогаются: при повторных запусках (папка уже
есть) ничего не досыпается. Реальные заметки и экспортированные `.html` в публичный
репозиторий не попадают (см. `.gitignore`).

## CI/CD — сборка всех платформ по `git push`
В репозитории три GitHub Actions workflow (`.github/workflows/`). Срабатывают на
`push` в `main`, на теги `v*` и вручную (`Actions → Run workflow`). Секреты для
базовых сборок НЕ нужны — форк собирается «из коробки».

| Workflow | Раннер | Что собирает | Где взять |
|---|---|---|---|
| `build-desktop` | macOS + Windows | macOS **универсальный** `.dmg`/`.app` (Intel+Apple Silicon), Windows x64 `.msi`/`.exe` | Artifacts прогона; на теге — черновик **Release** |
| `build-android` | Ubuntu | `.apk` — **Android 16 (API 36), только arm64, release, подписанный** (компактный) | Artifacts прогона |
| `build-ios` | macOS | без секретов — компиляция под Симулятор (проверка сборки); с секретами — подписанный `.ipa` | Artifacts прогона |

**Как выпустить релиз.** Поставь тег и запушь его:
```
git tag v1.0.0 && git push origin v1.0.0
```
`build-desktop` создаст **черновик** GitHub Release с установщиками mac/Windows —
проверь и нажми Publish. APK/iOS берутся из Artifacts соответствующих прогонов.

**Установщики без подписи.** macOS и Windows собираются **неподписанными** —
это нормально для бесплатного пайплайна, но при первом запуске система предупредит:
- macOS (Gatekeeper): ПКМ по `.app` → «Открыть», либо `xattr -dr com.apple.quarantine Notatnyk.app`.
- Windows (SmartScreen): «Подробнее» → «Выполнить в любом случае».
Чтобы убрать предупреждения — нужны платные сертификаты (Apple Developer ID / Windows code-signing) и их добавление в секреты.

### Android-APK: параметры и подпись
Сборка настроена под **компактный, современный** APK:
- **Android 16 (API 36)** — `bundle.android.minSdkVersion=36` в `tauri.conf.json`,
  плюс `compileSdk/targetSdk=36` в CI. ⚠️ **APK установится ТОЛЬКО на Android 16+.**
  Если нужен на твоём текущем телефоне (Android 14/15) — понизь `minSdkVersion`
  (напр. до 30) в `tauri.conf.json` и `sed`-строки в workflow. Это одна правка.
- **Только arm64** (`--target aarch64`) — без лишних ABI, размер минимальный.
- **Release, не debug** — оптимизированный.
- **Подпись:** без секретов CI подписывает **эфемерным** ключом (APK ставится, но
  обновление поверх невозможно — ключ каждый раз новый). Для стабильных/магазинных
  сборок задай секреты: `ANDROID_KEYSTORE_BASE64` (свой keystore в base64),
  `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
  Ключ **никогда** не коммить в открытый репозиторий.

> Не проверено на реальном Android-CI (нет раннера/устройства). Android 16 (API 36) —
> свежий; при первом прогоне возможны правки версий SDK/build-tools.

### iOS: честное ограничение
Установить приложение на **живой iPhone** нельзя без платного **Apple Developer**-
аккаунта ($99/год): Apple требует сертификат подписи и provisioning-профиль. Это
ограничение платформы, а не проекта. Поэтому по умолчанию `build-ios` только
проверяет, что проект собирается (сборка под Симулятор) — на телефон это не ставится.

Когда появится аккаунт — добавь секреты, и `build-ios` начнёт собирать подписанный
`.ipa` **тем же push’ем**, без правок workflow:
`IOS_CERTIFICATE_BASE64` (экспорт .p12 в base64), `IOS_CERTIFICATE_PASSWORD`,
`IOS_PROVISIONING_PROFILE_BASE64`, `APPLE_TEAM_ID`.

> Примечание про identifier: сейчас `com.local.notatnyk`. Для публикации в App Store /
> Google Play смени его в `src-tauri/tauri.conf.json` на свой реальный (напр.
> `ua.druk.notatnyk`) — `com.local.*` магазины не примут.

## Синтаксис (движок)

**Структура текста**

| Пишешь | Получаешь |
|---|---|
| `#` / `##` / `###` | заголовки (H1 — синий) |
| `[ ]` / `[x]` | чекбокс (клик переключает; `[x]` → серый + ГОТОВО) |
| `1.` | жирная нумерованная позиция |
| `- ` / `* ` | список с маркером |
| `! ` / `!! ` | выноска: `!` — жёлтая (warning), `!!` — красная (danger) |
| `> текст`, строкой ниже `> @Имя` | **цитата клиента**: карточка с аватаром-инициалом и именем; строки цитаты форматируются, но в Σ не идут |
| `---` / `===` | разделители (тонкий / жирный) |
| `\| A \| B \|` (строки через `\|`) | **таблица**: первая строка — жирные заголовки с фоном (кнопка спросит число столбцов/строк) |
| `// строка` | **скрытая строка**: не рендерится, но считается (см. «Скрытие») |
| `/*` … `*/` | **скрытый блок** строк: не рендерится, но считается |
| `[50x90мм]` | **эскиз изделия**: пропорциональный прямоугольник, X-крест, размерные стрелки снизу и справа |
| `[90x50мм r5]` | + скруглённые углы радиусом 5 мм (пересчитывается пропорционально масштабу) |
| `[90x50мм+3]` | + вылет (bleed) 3 мм: пунктирный внешний прямоугольник, внутри — чистовой размер |
| `[90x50мм+3 r5]` | оба модификатора вместе; внешний контур тоже скруглён концентрично |
| `[d50мм]` / `[D50mm]` | **эскиз круга**: окружность диаметром ø50 мм с центровым крестом и размерной стрелкой. Те же единицы, то же обтекание |

**Инлайн-стили**

| Пишешь | Получаешь |
|---|---|
| `**жирный**` | **жирный** |
| `*курсив*` | *курсив* |
| `~~зачёркнутый~~` | зачёркнутый |
| `== выделение ==` | выделение маркером |
| `` `код` `` | инлайн-код: моноширинный шрифт в рамке (как `` ` `` в стандартном `.md`) — удобно выделить и скопировать; внутри разметка и `грн` не срабатывают (дословно) |
| `->` `<-` `<->` | стрелки → ← ↔ (та же «→», что в расчёте формул). Длинные `-->` / `<--` — тоже. Пробел рядом (`a < b`) стрелку НЕ включает |
| `10x15`, `21х29,7` | размеры: `x`/`х` между цифрами → `×` (10×15). На расчёт не влияет — для умножения по-прежнему `*` |
| `5 м2`, `20 см3`, `100 m2` | площадь/объём: `2`/`3` после строчной единицы (`м`/`см`/`мм`/`км`/`дм`, `m`/`cm`/…) → степень `м²`, `см³`. `team2`, `H2O`, заглавная `М3` — не трогаются |
| `...` | многоточие `…` |
| `(c)` `(tm)` `(r)` | символы `©` `™` `®` (регистр и кирилл. `(с)` — тоже) |
| `+-5` `+/-0,5` | допуск `±` (только префикс значения: `±5`, `±0,5 мм`). В `10+-5` — это арифметика, `±` НЕ ставится |
| `https://…` | кликабельная ссылка |
| `[date]` / `[date:time]` | впечатывает дату в текст: `16.07.2026р` / `16.07.2026р. 14:23` (фиксируется при вводе, не пересчитывается) |

**Деньги и расчёты**

| Пишешь | Получаешь |
|---|---|
| `[листов] = 1125` | **переменная**: имя = число/формула (синим). Правишь в одном месте |
| `18400/1200*[листов]=` | **ссылка** на переменную в формуле → подставляется её число |
| `= 12 450 грн` | цена В Σ: сумма в синем чипе, знак `=` — цветом основного текста |
| `2490 грн` / `- 2490 грн` без `=` | прочая цена, НЕ в Σ |
| `грн/шт`, `грн./шт.` | цена за штуку — показывается, но НЕ в Σ |
| `55*3+7*(2.5+3.5)*2.55=` | **калькулятор**: → `272,1` (в превью, формула цела) |
| `18400/1200*1125= грн` | результат калькулятора как цена В Σ |
| `Итого: N грн` | подытог секции: сверяется с суммой позиций выше (✓ / ✕ + разница) |
| `[4000 шт]` / `[50 компл]` | **цена за единицу**: ближайшее сверху `Итого` ÷ кол-во → `(13,75 грн/шт)` |

**Калькулятор.** Пиши выражение и заверши знаком `=`. Поддержка `+ − * / % ^` и
скобок `( )`; результат всегда округляется до 2 знаков (`272,10` → `272,1`).
`%` — процент от суммы: `1000-20%` = `800`, `1000+20%` = `1200`, `200*15%` = `30`.
Если сразу после `=` стоит `грн` — результат идёт в Σ; если `грн/шт` — не идёт.

**Переменные.** Объяви вводные один раз — `[листов] = 1125` (можно формулой,
`[каш] = [листов]*2`) — и ссылайся на них в расчётах: `18400/1200*[листов]=`.
Поменял `[листов]` в одном месте — пересчиталась вся смета. В рендере имя и
значение — жирно-синим, формула — приглушённо-серым, а знаки `=` и `→` — цветом
основного текста (они держат структуру строки, а не являются частью формулы).
Работает сверху вниз (объявляй до использования); неизвестная ссылка оставляет
строку как есть.

**Скрытие.** `// строка` прячет одну строку; `/*` и `*/` на отдельных строках —
целый блок. Скрытое **не попадает в рендер, но продолжает считаться**: цены идут
в Σ, переменные объявляются и доступны видимым формулам. Так держат внутреннюю
себестоимость вне глаз клиента, не теряя её в сумме:

```
Дизайн = 1 200 грн
// Откат менеджеру = 500 грн
/* закупка, клиенту не показываем
Ламинация = 800 грн
Люверсы = 200 грн
*/
Печать = 3 000 грн
Итого: 5 700 грн        ✓ — скрытые 1 500 грн внутри
```

Хвост строки `/*` — свободная метка («зачем прячем»), в рендер не идёт.
Закрывающий `*/` должен стоять на строке один. Вложенные блоки не поддерживаются
(как и в JS). Если блок открыт и не закрыт, весь текст ниже исчез бы молча —
поэтому вместо этого внизу появляется выноска ⚠️ с номером строки, где открыт
`/*`. Скрытые чекбоксы считаются в счётчике, но кликнуть по ним нельзя — только
правкой текста.

**Секции и Итого.** Каждая строка `Итого` закрывает секцию и сверяет сумму
позиций (цен с `=`) выше неё со своим числом. Секций может быть несколько —
внизу окна показывается разбивка `Ітого(1) · Ітого(2) · … · Разом` и вердикт
«Співпадає з підрахунком».

**Редактор.** Слева — источник с номерами строк (при переносе номер занимает всю
высоту строки), справа — рендер. Фон источника слегка отличается от рендера
(токены `--src-bg`/`--src-num` в `styles.css`). Скролл панелей синхронизирован
по строкам: каждый блок рендера несёт `data-line` своей строки источника, позиция
интерполируется между якорями — таблицы и скрытые `/* блоки */` не сбивают
соответствие. Ведёт та панель, в которой находишься. На телефоне (≤640px)
номера строк скрыты.

Кнопка `?` в шапке открывает эту шпаргалку прямо в приложении, а кнопки над
редактором вставляют любой паттерн одним кликом.

**Язык / ключевые слова.** По умолчанию интерфейс **русский**. Кнопка **⚙** в
боковой панели открывает настройки: кнопки **Русский / Українська / English**
переключают весь интерфейс сразу, а поля ниже позволяют вручную поменять валюту
(`грн`), слово подытога (`Итого`), штамп готового (`ГОТОВО`), единицу «за штуку»
(`шт`), суффикс года (`г`) и слово «позиций». Тексты интерфейса и словари языков —
в `src/i18n.js`, ключевые слова движка по умолчанию — в `LOCALE` (`src/parser.js`),
выбор сохраняется в `config.json` (`{ lang, locale }`).
